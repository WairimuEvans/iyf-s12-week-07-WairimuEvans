# Week 7 — JavaScript Best Practices

Repository: `iyf-s12-week-07-WairimuEvans`

## Deliverable
A persistent, modular To-Do List with pure logic functions, ESLint, Prettier and Vitest tests.

## Setup
1. Ensure Node.js 22 or 24 is installed (`node --version`).
2. Open this repository folder in VS Code.
3. Run `npm install`.
4. Run `npm test`.
5. Run `npm run lint`.
6. Open `index.html` using VS Code Live Server.

## Project areas
- `js/`: modular To-Do application
- `cart/`: Lesson 13 shopping cart class build
- `notes/`: localStorage practice app
- `session-form/`: sessionStorage autosave exercise
- `daily-challenges/`: five daily challenge exercises
